# Feature list

The authoritative inventory for **MyWeb3.me Tools**. If something is not here,
it is not agreed — add it here before building it.

A set of XRP Ledger tools under the MyWeb3.me brand, launched at a hackathon on
`myweb3.me` and hosted on AWS until the full MyWeb3 app takes that address;
the tools then move to `tools.myweb3.me`. The tools were first built inside
the MW3 app (XRPL.directory's repository) from 2026-10-06, and lifted into
this repository on 2026-10-12 — section H.

Sources: the Canva file `DAHWhZFbx0s` ("XRPL Tools - Website"), a flow and
content spec rather than a visual design, and the client's package of
2026-10-12 (`game-day-runbook.md`, `myweb3-tools-infrastructure.txt`,
`xrpl-transactions.ts`, `xrp-ledger-template.toml`, `xrp-ledger-toml-rules.md`,
`myweb3-options.json`, logos), kept under `docs/client/`.

Status: `done` · `planned` · `blocked` (waits on the client) · `open` (needs a decision)

---

## The setup

| | |
|---|---|
| Hosting | AWS: the static site on S3 and CloudFront, and one function, `POST /api/sign`, on Lambda. Deploys from GitHub |
| Network | XRP Ledger Mainnet only (OT3, resolved by the client's runbook). Reads from a public node |
| Wallets | Xaman and Joey Wallet, through `xrpl-connect`. Xaman sign requests are made on the server, so its secret never reaches the browser |
| Every transaction | Carries MyWeb3's SourceTag, `2357011303` |
| Data | No database. Nothing is logged |
| Style | MW3, no exceptions. Titles on the system's scale: page titles `type-title`, window and card titles 22px (`type-title-sm`), running text `type-body`. A page title stands 16 above its line and the pair 32 above the page; the line is white — `PageHeader`. An empty field says its own name; a link shows `https://example.com` |
